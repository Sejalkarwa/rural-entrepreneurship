# Roots & Rise — Rural & Tribal Entrepreneurship

A responsive, no-backend static website for the theme **“Rural and Tribal Entrepreneurship”**.

## Files
- `index.html` — structure/content
- `style.css` — responsive visual design
- `script.js` — interactions and calculator

## Working interactions
- Sticky responsive navigation + mobile menu
- Smooth section navigation
- Scroll progress indicator
- Sector filters
- Sector pathway modal cards
- 60-second idea modal
- Illustrative value-addition calculator
- Community cart toast
- Support/pledge toast
- Responsive layout for mobile/tablet/desktop

## Research basis
Content was researched against official sources from TRIFED/Ministry of Tribal Affairs, Ministry of Rural Development (DAY-NRLM), Ministry of Food Processing Industries (PMFME), and ONDC. The site links directly to official sources in the support section.

## Run
Open `index.html` in a browser. Internet is only needed for the optional Google Fonts import and the linked official-source pages; the website itself has no framework or build step.
